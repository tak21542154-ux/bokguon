# 복구온 외부 접속 안내

㈜올림포스네트웍스 전략사업실 유경탁 파트장

PC를 켜 두면 **밖에서도 폰·노트북으로** 관리자 콘솔·보험사 포털·협력사 포털을
쓸 수 있다. 아래는 그 구조와, 반드시 한 번 해야 하는 일이다.

---

## 현재 설정 — 2단계 인증은 **꺼져 있다** (`BOKGUON_OTP_POLICY=off`)

지금은 **아이디·비밀번호만으로 밖에서 바로 들어올 수 있다.** 편의를 위해 끈
상태이며, 기능 자체는 그대로 살아 있어 한 줄만 바꾸면 다시 켜진다.

> ⚠ **알고 있어야 할 점** — 개인정보 안전성 확보조치 기준 제6조 제4항은 외부에서
> 개인정보처리시스템에 접속할 때 일회용 비밀번호 등 **안전한 인증수단**을 요구한다.
> 지금 콘솔에는 피해자 연락처와 협력사 계좌가 들어 있다. 사내 시험·단기 확인
> 용도라면 문제가 크지 않지만, **보험사에 링크를 주거나 상시 운영으로 넘어가기
> 전에는 반드시 다시 켤 것.** 지금은 비밀번호 강도와 로그인 잠금이 유일한 방어선이다.

### 다시 켜는 법 (1분)

1. `.env` 에서 `BOKGUON_OTP_POLICY=off` → `external` 로 변경
2. `복구온_외부공개_중지.bat` → `복구온_외부공개_링크열기.bat` (또는 서버 재시작)
3. 아래 "등록 절차"대로 폰 등록

### 등록 절차 (켠 뒤에 하면 된다)

켜면 등록 전까지 외부 접속이 막힌다. 등록은 **이 PC에서만** 가능하다.

1. 이 PC에서 <http://127.0.0.1:8771/admin> 접속 → 로그인
2. 좌측 **하단의 내 이름 클릭** → 내 계정
3. 맨 아래 **2단계 인증 등록하기**
4. 휴대폰 인증 앱(구글 OTP·MS Authenticator 등)으로 QR 촬영
   → 앱에 뜬 6자리 숫자를 입력 → **확인하고 켜기**
5. **복구 코드 8장이 딱 한 번 표시된다 — 반드시 저장할 것.**
   폰을 잃어버렸을 때 들어올 수 있는 유일한 방법이다.

등록하면 그때부터 밖에서 `아이디 → 비밀번호 → 폰 6자리` 로 들어온다.

> **등록·해제는 이 PC(내부망)에서만 된다.** 계정을 탈취당해도 공격자가 자기 폰을
> 2단계 인증으로 등록해 계정을 완전히 가져가는 것을 막기 위해서다.

## 접속 주소

바탕화면 **`복구온_외부주소.txt`** 에 항상 최신 주소가 적힌다.
(회사 Z 드라이브 `05_서비스_백엔드\_현재_외부주소.txt` 에도 같이 적힌다)

```
  관리자 콘솔 : https://…trycloudflare.com/admin
  보험사 포털 : https://…trycloudflare.com/insurer
  협력사 포털 : https://…trycloudflare.com/partner
```

**주소는 서버·PC가 다시 뜰 때마다 바뀐다.** 임시 터널이라 그렇다.
고정 주소(`bokguon.olymposcar.com`)를 쓰려면 아래 "고정 도메인" 참고.

## 켜고 끄기

| 하고 싶은 것 | 방법 |
|---|---|
| 외부 공개 시작 | `복구온_외부공개_링크열기.bat` (또는 재부팅 — 자동 시작됨) |
| 외부 공개 중지 | `복구온_외부공개_중지.bat` |
| 자동 시작 끄기 | `복구온_외부공개_중지.bat` 실행(감시자·터널을 내림) 뒤 `deploy\복구온_외부공개_등록.ps1 -Remove` 실행 — 로그온 자동시작은 예약 작업(`복구온_외부공개`)으로 등록되므로 `shell:startup` 폴더를 지우는 것만으로는 안 꺼진다 |
| 사무실에서만 쓰기 | 중지해도 `http://127.0.0.1:8771/admin` 은 계속 된다 |

로그온하면 감시자가 자동으로 뜬다. 감시자는 30초마다 확인해서
**서버나 터널이 죽으면 다시 살린다.** 기록은 `logs\supervisor.log`.

## 무엇이 지켜지고 있나

| 위협 | 방어 |
|---|---|
| 비밀번호 추측 | 5회 실패 시 계정 10분 잠금 + IP당 5분 10회 제한 |
| 비밀번호가 유출되면 | ⚠ **현재 막을 수단이 없다** — 2단계 인증을 껐기 때문. 켜면 폰 코드로 막힌다 |
| 코드 훔쳐보기·재전송 | (2단계 인증을 켰을 때) 한 번 쓴 코드는 재사용 불가 |
| IP 위조로 "사무실인 척" | 프록시 경유 흔적이 있으면 무조건 외부로 판정(위조 불가 — 실측 확인) |
| 주소 위조(Host 헤더) | 허용 주소 목록 밖이면 400 차단 |
| 통신 도청 | Cloudflare가 HTTPS 종단 + HSTS |
| 접속 추적 | 모든 요청의 실제 공인 IP·경로·결과를 기록(고시 §8, 730일 보관) |

**주소를 아는 사람은 로그인 화면까지 도달한다.** 링크를 공유하지 말 것.

## 고정 도메인 — `bokguon.com` (주소가 안 바뀌게)

임시 터널은 서버가 다시 뜰 때마다 주소가 바뀐다. 보험사에 링크를 주려면 고정
주소가 필요하다. **`bokguon.com` 은 2026-07-30 확인 시 미등록 상태**였다
(RDAP 404 + 네임서버 없음). `.co.kr` · `.kr` · `.net` · `.io` 도 모두 비어 있었다.

### 왜 회사 도메인(olymposcar.com) 하위가 아니라 새 도메인인가

`olymposcar.com` 은 **Vercel DNS** 에 물려 있다(회사 홈페이지가 거기서 뜬다).
Cloudflare 터널에 도메인을 붙이려면 그 도메인의 **네임서버를 Cloudflare 로
옮겨야** 하는데, 그러면 살아 있는 회사 홈페이지 DNS 를 건드리게 된다.
새 도메인을 쓰면 그 위험이 아예 없다.

### 순서 (도메인 구매 → 스크립트 1회)

**1) 도메인 구매** — 아래 중 아무 곳이나

| 곳 | 특징 |
|---|---|
| 가비아 | 회사가 `olymposcar.com` 을 여기서 쓰고 있어 청구·관리가 한곳에 모인다 |
| Cloudflare Registrar | 원가 판매(마크업 0). 단 이 경우 DNS 가 자동으로 Cloudflare 라 2번이 생략된다 |

**2) Cloudflare 에 도메인 추가** (무료 플랜으로 충분)
   - Cloudflare 가입 → Add a site → `bokguon.com`
   - Cloudflare 가 알려주는 네임서버 2개를 **등록업체(가비아 등)에서 변경**
   - Cloudflare 대시보드에서 상태가 **Active** 가 될 때까지 대기(보통 수십 분)

**3) 이 PC 에서 스크립트 1회 실행** — PowerShell 창에서 직접(중간에 브라우저가 뜬다)

```powershell
cd C:\Users\개발자3\Desktop\olympos_bot\bokguon_service\deploy; .\고정도메인_설정.ps1 -Domain bokguon.com
```

스크립트가 알아서 한다: Cloudflare 로그인 → 터널 생성 → DNS 연결 →
`config.yml` 작성 → `.env` 의 허용 주소에 도메인 추가 → 감시자 재시작.
끝나면 **`https://bokguon.com/admin`** 으로 고정된다.

> 2번의 네임서버 변경과 3번의 브라우저 로그인은 사람이 해야 한다(계정·결제가
> 필요한 일이라 대신 할 수 없다). 그래서 지금은 임시 터널로 먼저 서비스 중이다.

### 하위 주소로 나누고 싶으면

`-Domain app.bokguon.com` 처럼 서브도메인도 된다. 루트(`bokguon.com`)를
소개 홈페이지로 쓰고 콘솔만 서브도메인에 두는 구성이 흔하다.

## 곤란할 때

| 증상 | 확인 |
|---|---|
| 밖에서 "2단계 인증이 필요합니다" | 아직 등록 안 한 것 — 위 1번 절차 |
