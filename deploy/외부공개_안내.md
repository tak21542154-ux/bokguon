# 복구온 — 외부 공개 안내

㈜올림포스네트웍스 전략사업실 유경탁 파트장

외부(회사 밖) 사람에게 복구온을 보여주는 방법은 두 가지이며, 목적이 다릅니다.

| | ① 임시 공개 링크 | ② 소개 사이트 |
|---|---|---|
| 보이는 것 | **서비스 전체**(로그인·사건등록·입찰·정산) | 소개면 + 법정 게시물만 |
| 유지 | 내 PC + 창이 켜져 있는 동안 | 항상(무료·영구) |
| 주소 | 실행할 때마다 **바뀜** | 고정 |
| 용도 | 보험사·임원 **시연/검토** | 대외 홍보·명함용 |

---

## ① 임시 공개 링크 — 오늘 바로 (시연용)

**실행 방법**: `복구온_외부공개_링크열기.bat` 더블클릭.

1. 서비스 서버(운영 모드)가 뜹니다.
2. 터널 창에 `https://xxxx-xxxx.trycloudflare.com` 주소가 표시됩니다 → **그 주소를 공유**하면 됩니다.
3. 휴대폰·외부망 어디서든 접속됩니다(HTTPS 자동 적용).
4. **창을 닫으면 즉시 차단**됩니다.

### 주의 (중요)
- 주소는 **실행할 때마다 새로 생성**됩니다. 고정 주소가 필요하면 ②나 AWS 정식 배포로 가세요.
- 현재 **데모 계정 비밀번호를 그대로 두기로** 하셨습니다. 즉 **링크를 아는 사람은 관리자
  콘솔까지 접근**할 수 있습니다. → 링크는 **필요한 사람에게만** 공유하고, 시연이 끝나면
  **창을 닫아 주세요.**
- 계정을 잠그고 싶어지면: `python manage.py reset-pw admin admin` (역할·아이디별로 반복)

## ② 소개 사이트 — GitHub Pages (영구·무료)

`docs/` 폴더가 이미 만들어져 있습니다(`python build_pages.py`).
로그인·입찰 같은 기능은 서버가 필요해 **소개면과 법정 게시물만** 들어갑니다.

### 올리는 순서 (최초 1회, 약 10분)
1. https://github.com 가입/로그인 → **New repository** → 이름 예: `bokguon-site` → Public 생성
2. 이 폴더에서 (bokguon_service 안):
   ```
   git init
   git add docs
   git commit -m "복구온 서비스 소개 사이트"
   git branch -M main
   git remote add origin https://github.com/<내계정>/bokguon-site.git
   git push -u origin main
   ```
3. GitHub 저장소 → **Settings → Pages** → Source: `main` 브랜치 / 폴더: `/docs` → Save
4. 1~2분 뒤 `https://<내계정>.github.io/bokguon-site/` 로 공개됩니다.

### 갱신할 때
```
python build_pages.py
git add docs && git commit -m "소개면 갱신" && git push
```

### ⚠ 저장소에 올릴 때 반드시
- **`git add docs` 만** 하세요. 저장소 전체를 올리면 **앱 소스·`.env`·DB 가 그대로 공개**됩니다.
- `.gitignore` 에 `.env`, `*.db`, `uploads/` 가 들어 있는지 확인하세요.

### 실서비스 주소가 생기면
소개면의 '보험사/협력사 포털' 버튼을 실제 서비스로 연결하려면:
```
set BOKGUON_SERVICE_URL=https://복구온도메인
python build_pages.py
```
지정하지 않으면 포털 버튼은 **전화·이메일 문의로 대체**됩니다(죽은 링크를 만들지 않음).
관리자 콘솔 링크는 공개면에서 **항상 자동 제거**됩니다.

## ③ (권장 최종형) AWS 정식 배포

고정 도메인 + 24시간 운영이 필요해지면 `AWS_배포절차.md` 를 따르세요.
AWS 계정 생성과 카드 등록은 직접 하셔야 합니다.
배포 전 `python manage.py check` 가 **배포 불가 0건**이 되어야 합니다
(현재 잔여: 데모 비밀번호·데모 데이터·PG 사업자 기재·관리자 IP 허용대역).
