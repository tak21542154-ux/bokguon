# 복구온 — 앱스토어 · 플레이스토어 배포 가이드

㈜올림포스네트웍스 전략사업실 유경탁 파트장

복구온은 하나의 코드(웹)로 **① 설치형 웹앱(PWA) ② 구글 플레이스토어 ③ 애플 앱스토어**
세 경로에 모두 올릴 수 있도록 구성되어 있습니다. 서버를 새로 만들 필요 없이, **이미 만든
웹 서비스를 그대로 감싸서** 스토어에 제출합니다.

> ⚠ 전제: 앱은 **HTTPS 도메인**에서 동작해야 합니다(로컬 http 는 설치 안 됨).
>   `AWS_배포절차.md` 또는 `네이버클라우드_배포절차.md` 로 `https://복구온도메인` 이
>   살아 있어야 아래가 진행됩니다.

---

## 0. 지금 바로 되는 것 — 설치형 웹앱(PWA)

추가 작업 없이 **오늘 바로** 됩니다. 배포된 https 주소를 휴대폰 브라우저로 열면:

- **안드로이드(크롬)**: 주소창 메뉴 → "앱 설치" / "홈 화면에 추가" → 홈에 복구온 아이콘 생성
- **아이폰(사파리)**: 공유 → "홈 화면에 추가"
- 실행하면 주소창 없는 **전체화면 앱**으로 뜹니다(standalone). 아이콘·이름·색상은 이미 설정됨.

구현 요소(이미 포함): `static/manifest.webmanifest`(앱 이름·아이콘·색), `/sw.js`(서비스워커,
오프라인 셸·정적자산 캐시), `static/icons/`(192·512·마스커블·애플터치 아이콘).

**PWA 로 충분한 경우가 많습니다.** B2B(보험사·협력사) 내부용이면 스토어 심사 없이 설치 링크만
공유해도 됩니다. 스토어 등록이 꼭 필요할 때만 아래 1·2 로 갑니다.

---

## 1. 구글 플레이스토어 — TWA(권장, 가장 쉬움)

PWA 를 그대로 감싸는 **TWA(Trusted Web Activity)** 방식. 웹 화면이 100% 그대로 나옵니다.

1. **PWABuilder** (https://www.pwabuilder.com) 에 배포된 https 주소 입력 → "Package for stores"
   → Android 패키지(.aab) 다운로드. (또는 `bubblewrap` CLI: `npx @bubblewrap/cli init --manifest=https://도메인/static/manifest.webmanifest`)
2. **디지털 자산 링크**로 도메인 소유 증명: PWABuilder 가 준 `assetlinks.json` 을
   서버의 `https://도메인/.well-known/assetlinks.json` 에 올립니다(주소창을 숨기는 데 필수).
   ⚠⚠ [라운드308] `deploy/nginx_bokguon.conf` 의 숨김파일 차단 규칙이 이 경로도
   막고 있었다(정정 완료, 308라운드) — 서버의 `/opt/bokguon/.well-known/` 디렉터리를
   만들고 그 안에 `assetlinks.json` 을 두면 된다(nginx 설정을 이미 그렇게 배포했다면).
3. **구글 플레이 개발자 계정**(1회 $25) → 새 앱 → .aab 업로드 → 스토어 등록정보(설명·스크린샷·
   개인정보처리방침 URL=`/legal/privacy`) 작성 → 심사 제출.

소요: 계정만 있으면 반나절. 심사 수일.

---

## 2. 애플 앱스토어 — Capacitor(웹뷰 래핑)

애플은 TWA 를 허용하지 않으므로, 웹을 네이티브로 감싸는 **Capacitor** 를 씁니다.

1. 개발 PC(가능하면 **macOS**, Xcode 필요)에서:
   ```
   npm create @capacitor/app        # 또는 기존 폴더에 @capacitor/core, @capacitor/cli 설치
   npx cap init 복구온 com.olymposnetworks.bokguon
   ```
2. `capacitor.config.json` 의 `server.url` 을 배포 https 주소로 지정(원격 웹을 그대로 로드):
   ```json
   { "appId": "com.olymposnetworks.bokguon", "appName": "복구온",
     "server": { "url": "https://복구온도메인", "cleartext": false } }
   ```
3. iOS 프로젝트 추가·열기: `npx cap add ios` → `npx cap open ios` (Xcode 실행).
4. **애플 개발자 프로그램**(연 $99) → App Store Connect 에서 앱 생성 → Xcode 에서 서명·아카이브·
   업로드 → 심사 제출. 카메라(사진 업로드) 권한 설명 문구를 Info.plist 에 기입.
5. 같은 프로젝트로 **안드로이드**도 만들 수 있음: `npx cap add android`.

소요: 애플 계정·Mac 준비가 관건. 심사 수일~2주.

## 무엇을 고를까 (권장)

| 목적 | 권장 경로 | 비용 | 난이도 |
|---|---|---|---|
| 내부(보험사·협력사) 배포 | **PWA 설치 링크** | 0원 | 매우 쉬움 |
| 안드로이드 공개 | **TWA(PWABuilder)** | $25 1회 | 쉬움 |
| 아이폰 공개 | **Capacitor** | $99/년 | 보통(Mac 필요) |

> 어느 경로든 **웹 코드는 그대로**입니다. 스토어용으로 코드를 새로 짜지 않습니다.
> 제출 시 필요한 개인정보처리방침·이용약관·사업자정보 URL 은 이미 `/legal/*` 로 제공됩니다.

## 제출 전 체크리스트
- [ ] https 도메인 정상(모바일에서 로그인·사진 업로드 확인)
- [ ] 스토어 아이콘(512) · 스크린샷(폰 3~5장) 준비
- [ ] 개인정보처리방침 URL: `https://도메인/legal/privacy`
- [ ] 앱 카테고리: 비즈니스 / 생산성
- [ ] 카메라·저장소 권한 사유 문구(사진 업로드용)
